# Audit status

The tutor/contribution moderation model is being normalized.

Rules:
- Tutor registration starts `en_attente`.
- Only admin can change tutor certification status/date.
- Contributions start `en_attente`.
- Only admin/moderator can change moderation status.
- Authors may edit content but cannot self-approve.
- Certification is a badge, not a visibility gate.

This file documents the intended state model during the audit.
