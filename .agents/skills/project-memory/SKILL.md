# Project Memory

Maintenir une mémoire courte dans `PROJECT_MEMORY.md` à la racine du projet.

Règles :
- Lire `PROJECT_MEMORY.md` avant une tâche importante s'il existe.
- Ne jamais y stocker de secrets, tokens, mots de passe ou clés API.
- Enregistrer uniquement les informations utiles aux futures tâches.
- Éviter les doublons.
- Mettre à jour la mémoire après une décision importante ou une correction structurante.
- Garder le fichier compact et factuel.
