# Task Observer

Observer uniquement les préférences de travail utiles au développement.

À retenir :
- préférences de format des réponses ;
- niveau de détail souhaité ;
- façon préférée de tester et valider ;
- commandes et workflows récurrents ;
- décisions répétées concernant l'architecture.

Ne pas mémoriser :
- mots de passe ;
- tokens ;
- clés API ;
- données personnelles sensibles.

Stocker les observations utiles dans `WORKFLOW_MEMORY.md`.

Garder ce fichier court. Ne pas créer une entrée pour chaque interaction.
Ne jamais modifier le code uniquement pour mémoriser une préférence.
