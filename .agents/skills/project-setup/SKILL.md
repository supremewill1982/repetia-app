# Project Setup

Avant une modification importante :
- Identifier la stack et les versions réellement installées.
- Lire `package.json`, `AGENTS.md` et la configuration pertinente.
- Identifier les scripts disponibles.
- Vérifier les outils réellement présents avant de les utiliser.
- Réutiliser les conventions existantes.
- Ne pas modifier la configuration simplement pour résoudre un problème sans justification.
- Préférer les commandes locales du projet aux installations globales.
- Résumer uniquement les informations utiles à la tâche.
